AppCompatRadioButton

open class AppCompatRadioButton : RadioButton, TintableCompoundButton, TintableBackgroundView, EmojiCompatConfigurationView, TintableCompoundDrawablesView(source)

A RadioButton which supports compatible features on older versions of the platform, including:

  • Allows dynamic tint of its background via the background tint methods in androidx.core.widget.CompoundButtonCompat.
  • Allows setting of the background tint using buttonTint and buttonTintMode.

This will automatically be used when you use RadioButton in your layouts and the top-level activity / dialog is provided by appcompat. You should only need to manually use this class when writing custom views.
