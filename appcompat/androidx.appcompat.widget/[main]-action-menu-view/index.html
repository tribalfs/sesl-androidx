ActionMenuView

open class ActionMenuView : LinearLayoutCompat, MenuBuilder.ItemInvoker, MenuView(source)

(SESL modified) ActionMenuView is a presentation of a series of menu options as a View. It provides several top level options as action buttons while spilling remaining options over as items in an overflow menu. This allows applications to present packs of actions inline with specific or repeating content.
