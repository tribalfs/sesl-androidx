SeslShapeDrawable

@RequiresApi(api = 23)
open class SeslShapeDrawable : GradientDrawable

A specialized GradientDrawable that enables smooth corners by default.

This class extends GradientDrawable and, during inflation, attempts to invoke a hidden API (setSmoothCorner(true)) to enable smooth corner rendering. If the API is not available on the current platform, a warning is logged.

This class is intended for use on API level 23 and above.
