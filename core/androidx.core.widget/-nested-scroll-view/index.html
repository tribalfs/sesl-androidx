NestedScrollView

open class NestedScrollView : FrameLayout, NestedScrollingParent3, NestedScrollingChild3, ScrollingView, SeslScrollable

(SESL Modified) NestedScrollView is just like ScrollView, but it supports acting as both a nested scrolling parent and child on both new and old versions of Android. Nested scrolling is enabled by default.

Samsung Extension Software Library (SESL) Features:

  • Floating GoToTop Button: Enable via seslSetGoToTopEnabled to display an interactive floating "go to top" button during scrolling. Supports custom click callbacks (SeslOnGoToTopClickListener), One UI dynamic blur backgrounds (seslSetGoToTopBlurEnabled), S-Pen stylus hover gestures, and custom bottom padding/suppression.
  • AGSL Shader Fading Edges: Enable high-quality AGSL runtime shader fading edges at the scroll boundaries using seslSetFadingEdgeEnabled. Supports custom top/bottom heights, cubic-bezier easing interpolator slot overrides (SeslTopFadingEdgeOverrides, SeslBottomFadingEdgeOverrides), color customization, and window bottom alignment.
  • Hover Scrolling: Automatically scrolls content when an S-Pen or mouse pointer hovers near the top or bottom edges (seslSetHoverScrollEnabled). Hover trigger area padding and AppBar coordination can be configured via seslSetHoverTopPadding and seslSetBottomHoverScrollWithAppBar.
  • Custom Scrollbar &Padding Styling: Configurable horizontal padding background fill (seslSetFillHorizontalPaddingEnabled) and custom vertical scrollbar offsets.
  • SeslScrollable Interface: Implements SeslScrollable to expose a standardized contract for GoToTop, fading edge, and bounds coordination across SESL scrollable components.
