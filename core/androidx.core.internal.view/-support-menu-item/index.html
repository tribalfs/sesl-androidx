SupportMenuItem

@RestrictTo(value = LIBRARY_GROUP_PREFIX)
interface SupportMenuItem : MenuItem

(SESL variant) Interface for direct access to a previously created menu item. This version extends the one available in the framework to ensures that any necessary elements added in later versions of the framework, are available for all platforms.
