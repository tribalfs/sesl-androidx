SeslSelectLayoutSelectedListView

class SeslSelectLayoutSelectedListView @JvmOverloads constructor(context: Context, attrs: AttributeSet? = null, defStyleAttr: Int = 0) : SeslAppPickerGridView, LogTag

A SeslAppPickerGridView specialized for the selected-app area of SeslAppPickerSelectLayout.

Manages its own keyboard/system-bar-aware bottom footer, orientation-based layout (horizontal list in portrait, auto-fit grid in landscape), and sesl rounded corner decorations including a system bar rounded corner decoration.
