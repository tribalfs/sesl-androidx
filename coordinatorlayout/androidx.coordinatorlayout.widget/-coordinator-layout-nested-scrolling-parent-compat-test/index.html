CoordinatorLayoutNestedScrollingParentCompatTest

open class CoordinatorLayoutNestedScrollingParentCompatTest(source)

Small integration tests that verify that CoordinatorLayout works correctly with older nested scrolling implementations. This includes methods that are rendered obsolete by nested scrolling v2 or v3, and deprecated methods on CoordinatorLayout.Behavior that are related to nested scrolling. This test currently only covers calls to onNestedScroll and onNestedScroll
