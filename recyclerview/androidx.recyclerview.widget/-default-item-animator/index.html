DefaultItemAnimator

open class DefaultItemAnimator : SimpleItemAnimator(source)

(SESL modified) This implementation of RecyclerView.ItemAnimator provides basic animations on remove, add, and move events that happen to the items in a RecyclerView. RecyclerView uses a DefaultItemAnimator by default.
